# Mongolian-phonetic keyboard — Windows

Латин үсгээр бичиж байгаа юм шиг крилл үсгээр бичих **Windows**-д зориулсан keyboard layout.

Жишээ нь: **`Mongol hel`** гэж бичихэд **`Монгол хэл`** гэж гарна.

Товчлуурын байршил цээжлэх, гар дээрээ крилл наах хэрэггүй.

## Суулгах

1. [Releases](../../releases) хэсгээс `MongolianPhonetic-Setup.exe`-г татна.
2. Ажиллуулаад **Finish** дарна (админ эрх шаардахгүй).
3. Дэлгэцийн баруун доод буланд цэнхэр **«М»** дүрс гарна — бэлэн боллоо.

Програм Windows асахад автоматаар эхэлнэ.

> Windows SmartScreen «unknown publisher» гэж анхааруулж магадгүй (програм цахим гарын үсэггүй).
> **More info → Run anyway** дарна.

## Ашиглах

| Үйлдэл | Тайлбар |
|---|---|
| Tray дүрс дээр зүүн товч / **Ctrl+Alt+M** | Монгол ↔ Англи (хэвийн) горим солих |
| Tray дүрс дээр баруун товч | Цэс (Exit) |
| Цэнхэр «М» / саарал «A» | Монгол асаалттай / унтраалттай |

## Товчлуурын жагсаалт

| Крилл | Бичих |
|---|---|
| ц | `ts` эсвэл `c` |
| ч | `ch` |
| ш | `sh` эсвэл `x` |
| я | `ya` |
| е | `ye` |
| ё | `yo` |
| ю | `yu` |
| ө | `q` |
| ү | `w` |
| в | `v` |
| й | `i'` |
| ай | `ai` |
| үй | `wi` |
| ы | `y` |
| ь | `'` |
| Ь | `''` (хоёр single-quote) |
| ъ | `"` |
| Ъ | `""` |
| ₮ | `Shift+4` |

Бүх дүрэм анхны macOS layout-тай яг ижил (`tools/Mongolian-phonetic.keylayout`-оос автоматаар үүсгэсэн).

## Хязгаарлалт

- Администратор эрхээр ажиллаж буй цонхонд бичихийн тулд програмыг мөн администраторээр ажиллуулна.
- `Ctrl`, `Alt`, `Win` дарсан хослолууд (shortcut) өөрчлөгдөхгүй.

## Өөрөө build хийх

```sh
sudo apt install mingw-w64 nsis python3
./build.sh
```

Үр дүн: `build/MongolianPhonetic-Setup.exe`

Layout-ын логикийг (Windows-гүйгээр) шалгах:

```sh
cd src && gcc -o test test.c engine.c && ./test
```

## Хэрхэн ажилладаг

Windows-ийн стандарт layout `ts → ц`, `sh → ш` зэрэг дарааллыг дэмждэггүй тул жижиг tray програм
low-level keyboard hook ашиглан дарсан товчийг барьж, тохирох крилл үсгийг `SendInput`-аар илгээнэ.
Товчлуурыг байрлалаар (scancode) таньдаг тул системийн гарын хэл ямар байсан ч ажиллана.

## Талархал

Layout болон дүрмийг зохиогч: [amgaa](https://github.com/amgaa/mongolian-phonetic).
Энэ репо нь түүний macOS layout-ыг Windows руу шилжүүлсэн хувилбар. Лицензийн талаар эх репогийн зохиогчтой холбогдоно уу.
